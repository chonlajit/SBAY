# SBAY Smart Bin - คู่มือการต่อวงจร Servo และ ปุ่มทดสอบ (อัปเดตล่าสุด)

เอกสารนี้ใช้อธิบายการต่อสายสัญญาณและการตั้งค่าขามอเตอร์ Servo รวมถึงสวิตช์ปุ่มกดสำหรับการทดสอบเบื้องต้นของถังขยะอัจฉริยะ (SBAY Smart Bin)

---

## 🔌 1. การต่อสายมอเตอร์ Servo และระบบไฟ (สำคัญมาก!)

เราใช้มอเตอร์ Servo ตัวใหญ่ทั้งหมด 2 ตัว ทำหน้าที่คัดแยกขยะ (Sort) และปล่อยขยะลงถัง (Release)
ให้ต่อสายสัญญาณเข้ากับ Raspberry Pi (ตั้งค่าโค้ดเป็นโหมด **GPIO.BCM**) ดังนี้:

| อุปกรณ์ | หน้าที่การทำงาน | BCM Pin (ในโค้ด) | Physical Pin (บนบอร์ด) |
| :--- | :--- | :---: | :---: |
| **Servo Sort** | หมุนแผ่นปัดเพื่อคัดแยกขยะไปตามช่องต่างๆ | **18** | **12** |
| **Servo Release**| หมุนแผ่นรองให้คว่ำลง เพื่อปล่อยขยะร่วงลงถัง | **19** | **35** |

### ⚠️ ข้อควรระวังเรื่องระบบไฟ (Power Supply)
- **แหล่งจ่ายไฟ:** **ห้าม!** ดึงไฟ 5V จาก Raspberry Pi มาเลี้ยง Servo เด็ดขาด เพราะไฟจะไม่พอและทำให้บอร์ดดับ/พังได้
- **สเปคที่ต้องการ:** ต้องใช้อะแดปเตอร์ภายนอก **5V หรือ 6V ที่จ่ายกระแสไฟได้ 3A ถึง 5A ขึ้นไป**
- **สายสีแดง (VCC):** ต่อเข้าขั้วบวก (+) ของอะแดปเตอร์
- **สายสีน้ำตาล/ดำ (GND):** ต่อเข้าขั้วลบ (-) ของอะแดปเตอร์ **และต้องลากสายมาเชื่อมกับขา GND บน Raspberry Pi ด้วย** หากไม่ต่อกราวด์ร่วมกัน Servo จะไม่ทำงาน

## 🎛️ 2. การต่อสายปุ่มกดสวิตช์ 4 ตัว (สำหรับการทดสอบ)

หากต้องการทดสอบการทำงานของมอเตอร์ด้วยปุ่มกด โดยไม่ผ่านกล้อง ให้ต่อปุ่มกดดังนี้:
*(ในโค้ดเปิดใช้งาน Internal Pull-Up ไว้ จึงไม่ต้องต่อตัวต้านทานเพิ่ม และระบบจะ**ทำงานตอนที่ "ปล่อยนิ้ว"** ออกจากปุ่ม เพื่อป้องกันการกดค้าง)*

| จำลองการหยอดขยะประเภท | BCM Pin | Physical Pin | การต่อสาย |
| :--- | :---: | :---: | :--- |
| **1. ขวดพลาสติกใส** (`PLASTIC_BOTTLE`) | **22** | **15** | ขาด้านนึงต่อ BCM 22, อีกด้านต่อ GND |
| **2. กระป๋องอลูมิเนียม** (`ALUMINUM_CAN`) | **23** | **16** | ขาด้านนึงต่อ BCM 23, อีกด้านต่อ GND |
| **3. กล่องกระดาษ** (`BEVERAGE_CARTON`) | **24** | **18** | ขาด้านนึงต่อ BCM 24, อีกด้านต่อ GND |
| **4. ปุ่มรีเซ็ต (Reset)** (สั่งให้กลับค่าเริ่มต้น) | **25** | **22** | ขาด้านนึงต่อ BCM 25, อีกด้านต่อ GND |

**หมายเหตุ:** ขา GND สามารถใช้ช่อง Physical Pin ขา **14, 20 หรือ 34** ที่ว่างอยู่บนบอร์ดได้เลย (สำหรับสวิตช์ตัวที่ 4 แนะนำให้พ่วงกับ GND ขา 20 ซึ่งอยู่ติดกับขา 22 พอดี)

## 📐 3. การตั้งค่าองศาการหมุนของ Servo

หากหน้างานจริงองศาการปัดไม่ตรง หรือแผ่นรองปิดไม่สนิท สามารถเข้าไปแก้ไขตัวเลขในไฟล์ `hardware/servo.py` ได้ที่บรรทัดบนสุด:

```python
# ค่าเริ่มต้น (จุดศูนย์) ของระบบ
DEFAULT_SORT_ANGLE = 90    # คืนค่าตัวปัดคัดแยกกลับมาตรงกลาง
DEFAULT_RELEASE_ANGLE = 0  # คืนค่าตัวแผ่นรองกลับมาตำแหน่งเดิม (แบนราบ)
```
*หมายเหตุ: ทุกครั้งที่กระบวนการทิ้งขยะเสร็จสิ้น (หมุนลง 45 องศาแล้ว) ระบบจะสั่งคืนค่ามอเตอร์ทั้ง 2 ตัวกลับมาที่ค่า `DEFAULT` เหล่านี้เสมอ เพื่อเตรียมพร้อมรับขยะชิ้นต่อไป*

**ค่าองศาแยกตามประเภท (แก้ไขในฟังก์ชัน `sort_item`):**
- ขวดพลาสติกใส (ช่องตรงกลาง) = ใช้ค่า `DEFAULT_SORT_ANGLE` (90 องศา)
- กระป๋องอลูมิเนียม (ช่องขวาล่าง) = `30 องศา`
- กล่องกระดาษ (ช่องซ้ายล่าง) = `150 องศา`

## 🎯 4. วิธีค้นหาค่าองศาที่เป๊ะที่สุด (Calibration พร้อมกล้องสด)

หากต้องการสุ่มหาองศาที่พอดีกับหน้างานจริง สามารถใช้โปรแกรมตัวช่วยที่เชื่อมต่อกล้องสด:
1. เปิด Terminal พิมพ์คำสั่ง:
   ```bash
   cd settings && python3 calibrate_servo.py
   ```
2. หน้าต่างแสดงผลภาพสดจากกล้องจะเปิดขึ้นมาอัตโนมัติ พร้อมเส้นเล็ง Crosshair และกรอบ Crop
3. เลือก Servo ที่ต้องการ Calibrate ใน Terminal (1=Sort, 2=Release, 3=Drop, 4=Return)
4. ป้อนค่าองศาลงไป และสังเกตตำแหน่งของก้านปัด/แผ่นรองบนหน้าจอแบบเรียลไทม์

## 🚀 5. วิธีรันทดสอบ Servo พร้อมเปิดกล้องสด (Test Servo & Live Camera)

สคริปต์ทดสอบใหม่พร้อมหน้าต่างภาพสดจากกล้องและการกดปุ่ม 1-4:
1. เข้าไปที่โฟลเดอร์ tests:
   ```bash
   cd tests
   python3 test_servo.py
   ```
2. หน้าต่างกล้องจะเปิดขึ้นมาพร้อม HUD แนะนำปุ่ม สามารถกดปุ่มที่คีย์บอร์ดได้ทันที:
   - **`1`**: จำลองขวดพลาสติก (`PLASTIC_BOTTLE`)
   - **`2`**: จำลองกระป๋องอลูมิเนียม (`ALUMINUM_CAN`)
   - **`3`**: จำลองกล่องกระดาษ (`BEVERAGE_CARTON`)
   - **`4`**: 🔄 จำลองทิศคืนขวด (`RETURN BOTTLE`)
   - **`d`**: จำลองการเปิดรับขวด (`drop_item`)
   - **`r`**: รีเซ็ตมอเตอร์กลับสู่จุดศูนย์ (`reset_position`)
   - **`q` หรือ `ESC`**: ออกจากโปรแกรม
3. หรือรันแบบ CLI ดั้งเดิม:
   ```bash
   python3 test_servo_cli.py
   ```
