# SBAY Smart Bin - คู่มือการต่อวงจร Servo และ ปุ่มทดสอบ

เอกสารนี้ใช้อธิบายการต่อสายสัญญาณและการตั้งค่าขามอเตอร์ Servo รวมถึงสวิตช์ปุ่มกดสำหรับการทดสอบเบื้องต้นของถังขยะอัจฉริยะ (SBAY Smart Bin)

---

## 🔌 1. การต่อสายมอเตอร์ Servo

เราใช้มอเตอร์ Servo ทั้งหมด 2 ตัว ทำหน้าที่คัดแยกขยะ (Sort) และปล่อยขยะลงถัง (Release)
ให้ต่อสายสัญญาณเข้ากับ Raspberry Pi (ตั้งค่าโค้ดเป็นโหมด **GPIO.BCM**) ดังนี้:

| อุปกรณ์ | หน้าที่การทำงาน | BCM Pin (ในโค้ด) | Physical Pin (บนบอร์ด) |
| :--- | :--- | :---: | :---: |
| **Servo Sort** | หมุนแผ่นปัดเพื่อคัดแยกขยะไปตามช่องต่างๆ | **18** | **12** |
| **Servo Release**| หมุนแผ่นรองให้คว่ำลง เพื่อปล่อยขยะร่วงลงถัง | **19** | **35** |

### 💡 การต่อสายไฟ (VCC & GND) ของ Servo:
- **สายสีแดง (VCC):** แนะนำให้ใช้แหล่งจ่ายไฟ 5V แยกต่างหากจาก Raspberry Pi (เนื่องจากมอเตอร์อาจดึงกระแสไฟเยอะจนบอร์ดรีสตาร์ท)
- **สายสีน้ำตาล/ดำ (GND):** นำไปต่อร่วมกับ GND ของบอร์ด Raspberry Pi และ GND ของแหล่งจ่ายไฟ 5V แยกด้วย

## 🎛️ 2. การต่อสายปุ่มกดสวิตช์ (สำหรับการทดสอบ)

หากต้องการทดสอบการทำงานของมอเตอร์ด้วยปุ่มกด 3 ตัว โดยไม่ผ่านกล้อง ให้ต่อปุ่มกดดังนี้:
*(ในโค้ดเปิดใช้งาน Internal Pull-Up ไว้ จึงไม่ต้องต่อตัวต้านทานเพิ่ม)*

| จำลองการหยอดขยะประเภท | BCM Pin (ในโค้ด) | Physical Pin (บนบอร์ด) | การต่อสาย |
| :--- | :---: | :---: | :--- |
| **ขวดพลาสติกใส** (`PLASTIC_BOTTLE`) | **22** | **15** | ขาด้านนึงต่อ BCM 22, อีกด้านต่อ **GND** |
| **กระป๋องอลูมิเนียม** (`ALUMINUM_CAN`) | **23** | **16** | ขาด้านนึงต่อ BCM 23, อีกด้านต่อ **GND** |
| **กล่องกระดาษ** (`BEVERAGE_CARTON`) | **24** | **18** | ขาด้านนึงต่อ BCM 24, อีกด้านต่อ **GND** |

**หมายเหตุ:** ขา GND สามารถใช้ช่อง Physical Pin ขา **14, 20 หรือ 34** ที่ว่างอยู่บนบอร์ดได้เลย

## 📐 3. การตั้งค่าองศาการหมุนของ Servo

หากหน้างานจริงองศาการปัดไม่ตรง หรือแผ่นรองปิดไม่สนิท สามารถเข้าไปแก้ไขตัวเลขในไฟล์ `hardware/servo.py` ได้:

**Servo Sort (คัดแยก):** 
- ขวดพลาสติกใส (ช่องตรงกลาง) = `90 องศา`
- กระป๋องอลูมิเนียม (ช่องขวาล่าง) = `30 องศา`
- กล่องกระดาษ (ช่องซ้ายล่าง) = `150 องศา`

**Servo Release (ปล่อยขยะลงถัง):**
- สถานะสแตนด์บาย / แบนราบ = `0 องศา`
- หมุนคว่ำลงเพื่อปล่อยขยะร่วง = `45 องศา`

*(หากแผ่นปัดหมุนกลับทาง ให้ลองสลับองศาระหว่าง 30 กับ 150 ดูครับ)*

## 🚀 4. วิธีการรันทดสอบ

1. เปิด Terminal บน Raspberry Pi
2. เข้าไปที่โฟลเดอร์หลักของตัวเครื่อง
   ```bash
   cd bin-device
   ```
3. รันสคริปต์สำหรับทดสอบด้วยปุ่มกด
   ```bash
   python3 test_servo_switch.py
   ```
4. กดปุ่มที่ต่อไว้ทีละปุ่ม เพื่อดูการทำงานของ Servo หากต้องการออกจากโปรแกรมให้กด `Ctrl + C`
