# SBAY Smart Bin - ข้อมูลการเชื่อมต่อฮาร์ดแวร์ (Pin Configuration)

เอกสารนี้รวบรวมการตั้งค่าขา (Pin) GPIO ทั้งหมดที่ใช้งานในโปรเจกต์ SBAY Smart Bin บนบอร์ด Raspberry Pi (อ้างอิงตาม BCM Pin)

## ตารางสรุปการใช้งาน GPIO (Raspberry Pi BCM)

| อุปกรณ์ (Component) | ตัวแปรในโค้ด (`config.py`) | BCM Pin | Physical Pin | หน้าที่การทำงาน |
| :--- | :--- | :---: | :---: | :--- |
| **IR Sensor** | `IR_PIN` | **17** | **11** | เซนเซอร์อินฟราเรด ตรวจจับว่ามีขยะถูกหยอดลงมาหรือไม่ |
| **Servo Sort** | `SERVO_SORT_PIN` | **18** | **12** | มอเตอร์หมุนแผ่นปัดเพื่อคัดแยกขยะไปตามช่องต่างๆ (พลาสติก, กระป๋อง, กล่อง) |
| **Servo Release** | `SERVO_RELEASE_PIN` | **19** | **35** | มอเตอร์หมุนแผ่นรองให้คว่ำลง เพื่อปล่อยขยะร่วงลงถัง |
| **ปุ่มจำลองขวดพลาสติก** | `RESET_PIN_PLASTIC` | **22** | **15** | สวิตช์ปุ่มกด จำลองการทำงานเมื่อเจอขวดพลาสติก (สำหรับทดสอบ) |
| **ปุ่มจำลองกระป๋อง** | `RESET_PIN_CAN` | **23** | **16** | สวิตช์ปุ่มกด จำลองการทำงานเมื่อเจอกระป๋องอลูมิเนียม (สำหรับทดสอบ) |
| **ปุ่มจำลองกล่องกระดาษ** | `RESET_PIN_CARTON` | **24** | **18** | สวิตช์ปุ่มกด จำลองการทำงานเมื่อเจอกล่องกระดาษ (สำหรับทดสอบ) |
| **ปุ่มรีเซ็ต** | `RESET_PIN_ALL` | **25** | **22** | สวิตช์ปุ่มกด เพื่อรีเซ็ตค่าของมอเตอร์กลับสู่จุดเริ่มต้น |

---

### หมายเหตุการเชื่อมต่อ (Wiring Notes)
- **โหมด GPIO:** โค้ดทั้งหมดใช้การอ้างอิงพินแบบ `GPIO.BCM`
- **GND (กราวด์):** สามารถใช้ขา Physical Pin ใดก็ได้ที่เป็น GND บนบอร์ด เช่น **6, 9, 14, 20, 30, 34, 39** แต่สำหรับอุปกรณ์ฮาร์ดแวร์ที่ใช้ไฟจากแหล่งจ่ายภายนอก (เช่น มอเตอร์ Servo) **จำเป็นต้องเชื่อมกราวด์ (GND) จากแหล่งจ่ายไฟนั้นมารวมกับ GND ของ Raspberry Pi ด้วย** เสมอ
- **ปุ่มกด (Switch):** โค้ดเปิดใช้งาน Internal Pull-Up Resistor ไว้แล้ว จึงสามารถต่อขาข้างหนึ่งเข้ากับ BCM Pin และอีกข้างเข้ากับ GND ได้โดยตรง ไม่ต้องต่อตัวต้านทานเพิ่ม
- **Servo Motor:** ห้ามดึงไฟ 5V จากตัว Raspberry Pi ไปจ่ายให้ Servo เด็ดขาด เนื่องจากกระแสไฟไม่พอ ให้ใช้แหล่งจ่ายไฟ (Adapter) 5V-6V 3A ขึ้นไป แยกต่างหาก

## 📐 การตั้งค่าและปรับองศา Servo (Calibration)

หากประกอบถังขยะแล้วองศาการปัดขยะไม่ตรงช่อง หรือแผ่นรองปิดไม่สนิท คุณสามารถค้นหาองศาที่ถูกต้องและตั้งค่าใหม่ได้ดังนี้:

### 1. วิธีค้นหาองศาที่เป๊ะที่สุดของหน้างาน (Calibration)
ในโปรเจกต์มีสคริปต์สำหรับทดสอบหมุน Servo เพื่อหาองศาที่เหมาะสม:
1. เปิด Terminal บน Raspberry Pi แล้วเข้าไปที่โฟลเดอร์โปรเจกต์
   ```bash
   cd bin-device
   ```
2. รันสคริปต์ `calibrate_servo.py`
   ```bash
   python3 calibrate_servo.py
   ```
3. โปรแกรมจะให้เลือกมอเตอร์: 
   - พิมพ์ `1` สำหรับ **Servo Sort** (ตัวปัดคัดแยก)
   - พิมพ์ `2` สำหรับ **Servo Release** (ตัวปล่อยขยะลงถัง)
4. ป้อนตัวเลของศา (0-180) ลงไป มอเตอร์จะหมุนไปตามองศานั้นทันที
5. ทดลองป้อนตัวเลขไปเรื่อยๆ จนกว่าจะได้ตำแหน่งที่ตรงกับช่องทิ้งขยะพอดี และ **จดตัวเลขเหล่านั้นไว้**

### 2. วิธีนำค่าที่ได้ไปตั้งค่าในระบบ
เมื่อได้องศาที่ต้องการแล้ว ให้นำไปอัปเดตในไฟล์ `config.py` หรือไฟล์ตั้งค่าสภาพแวดล้อม (`.env`) ของระบบ:

**ในไฟล์ `.env` หรือ `config.py`:**
```python
# --- Servo Angles Configuration ---
# ตำแหน่งเริ่มต้น (จุดศูนย์ - รอรับขยะ)
DEFAULT_SORT_ANGLE = 90
DEFAULT_RELEASE_ANGLE = 90

# องศาการคัดแยก (Sort) สำหรับขยะแต่ละประเภท
SORT_ANGLE_PLASTIC = 90   # ขวดพลาสติก (เช่น ช่องตรงกลาง)
SORT_ANGLE_CAN = 30       # กระป๋องอลูมิเนียม (เช่น ช่องขวา)
SORT_ANGLE_CARTON = 150   # กล่องกระดาษ (เช่น ช่องซ้าย)

# องศาการปล่อย (Release) เทขยะลงถัง
RELEASE_ANGLE_PLASTIC = 45
RELEASE_ANGLE_CAN = 135
RELEASE_ANGLE_CARTON = 135
```
*หมายเหตุ: หลังจากปล่อยขยะลงถังเสร็จ ระบบจะสั่งให้มอเตอร์กลับมาที่ค่า `DEFAULT` เสมอเพื่อเตรียมพร้อมรับขยะชิ้นต่อไป*

สำหรับรายละเอียดเชิงลึกทั้งหมดสามารถอ่านเพิ่มเติมได้ในไฟล์ `readme_servo.md`
