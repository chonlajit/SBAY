# SBAY - Smart Recycle Bin System ♻️

SBAY is an intelligent recycling system powered by IoT and AI object detection. It recognizes recyclable items (like bottles and cans) using a webcam and rewards users with credits.

## 🚀 Tech Stack

- **Frontend**: Next.js (TypeScript, Tailwind CSS)
- **Backend**: Java Spring Boot
- **Database**: MongoDB
- **AI / IoT**: Python (YOLOv8 Object Detection)
- **Infrastructure**: Docker & Docker Compose

## 📂 Project Structure

```bash
SBAY/
├── backend/          # Spring Boot API & Logic
├── frontend/         # Next.js Dashboard & User Interface
├── iot-device/       # Python scripts for webcam & AI detection
├── docker-compose.yml # Container orchestration
└── start_fast.ps1    # Quick start script for Windows
```

## 🛠️ Prerequisites

Ensure you have the following installed:
- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Node.js](https://nodejs.org/) (LTS recommended)
- [Java JDK 17+](https://adoptium.net/)
- [Python 3.9+](https://www.python.org/)

## ⚡ Quick Start (Windows)

The easiest way to run the entire system is using the provided PowerShell script:

```powershell
./start_fast.ps1
```

This script will automatically:
1. Start the **Backend** and **MongoDB** containers via Docker.
2. Launch the **Frontend** (Next.js) development server.
3. Start the **Python Webcam Detector** for object recognition.

### Access Points
- **Frontend Dashboard**: [http://localhost:3000](http://localhost:3000)
- **Admin QR Code**: [http://localhost:3000/admin/qr](http://localhost:3000/admin/qr)
- **Backend API**: [http://localhost:8080](http://localhost:8080) (default Spring Boot port)

## 🔧 Manual Setup

If you prefer to run components individually:

### 1. Backend & Database
```bash
docker-compose up -d backend mongodb
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```

### 3. IoT Device (AI Detection)
```bash
# Recommended to use a virtual environment
cd iot-device
pip install -r requirements.txt
python webcam_detector.py
```
